# AWS環境ランチャー（Chrome拡張機能）

複数のAWSアカウント/環境のログインURLとスイッチロール情報を登録し、ワンクリックで開くための個人用Chrome拡張機能です。

※個人利用専用ツールのため、パスワードは暗号化せず `chrome.storage.local`（このPC・このChromeプロファイル内のみ）に平文で保存します。共有PCや同期を有効にした複数端末での利用は想定していません。

## 機能

1. **ログイン環境の登録**: 表示名・AWSアカウントID・ログインURL・ユーザー名・パスワードを登録し、ポップアップから1クリックでログインURLを開けます（ユーザー名・パスワードはコピー用ボタンあり）。
2. **表示名によるわかりやすい管理**: 「本番環境」「開発環境」など自由に表示名を設定できます。
3. **スイッチロールの登録**: AWSマネジメントコンソールへログイン済みであることを前提に、アカウントID・ロール名・表示色からスイッチロールURL（`https://signin.aws.amazon.com/switchrole?...`）を生成し、1クリックで切り替えられます。
   - 遷移先のスイッチロール画面では、「Switch Role」ボタンも自動で押下されます（ポップアップの「スイッチロールで開く」から遷移した場合のみ）。ボタンが見つからない場合はトーストで知らせ、手動で押すことで従来通り切り替えられます。
4. **サインイン画面への自動入力**: ログイン情報の「開く」を押すと、遷移先のAWSサインインページ（`*.signin.aws.amazon.com`）のアカウントID・ユーザー名・パスワード欄に自動入力します。
   - id/name等の固定属性には依存せず、パスワード欄（`type="password"`）を起点に、同じフォーム内の空のテキスト欄をプレースホルダ/ラベル文言から判別する方式のため、AWS側の画面構成（アカウントID欄の有無等）が多少変わっても追従しやすくしています。
   - 自動入力するだけで、サインインボタンの押下やMFA入力は行いません（安全確認のため必ず手動で行ってください）。
   - AWS側のページ構造変更や多要素認証・reCAPTCHA等の割り込みで自動入力できない場合があります。その場合は従来どおりコピー用ボタンで貼り付けてください。
5. **タブでの表示切り替え**: ポップアップは「ログイン環境」「スイッチロール」の2つのタブに分かれています。最後に選んだタブは次回起動時も記憶されます。
6. **表示順の並び替え**: 管理画面（options.html）の一覧で、同じ種別（ログイン/スイッチロール）の中で ↑/↓ ボタンにより自由に並び順を変えられます。ここで変えた順番はポップアップの一覧にも反映されます。
7. **設定のエクスポート/インポート**: 管理画面の「エクスポート」で登録内容をJSONファイルとしてダウンロードし、別のブラウザ/PCで「インポート」から読み込むことで設定を移行できます。
   - インポートは常に既存の登録内容への「追加」です（上書き・削除は行いません）。IDは衝突を避けるためインポート時に採番し直します。
   - エクスポートファイルにはパスワードが平文で含まれるため、保存先・受け渡し方法（USBメモリ、クラウドストレージ等）には注意してください。

## フォルダ構成

```
aws-env-launcher-extension/
├── manifest.json       # 拡張機能定義 (Manifest V3)
├── common.js           # ストレージ操作・URL生成の共通ロジック
├── popup.html/css/js   # ツールバーから開くポップアップ（一覧・起動・コピー）
├── options.html/css/js # 管理画面（登録・編集・削除）
├── content-fill.js     # AWSサインインページへの自動入力（コンテンツスクリプト）
├── content-switchrole.js # スイッチロール画面でのSwitch Roleボタン自動押下（コンテンツスクリプト）
└── icons/
    ├── generate_icons.py  # アイコン生成スクリプト（Pillow使用）
    └── icon16/48/128.png  # 生成済みアイコン
```

## インストール方法（開発者モードで読み込み・Chrome/Edge）

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. このフォルダ（`aws-env-launcher-extension`）を選択する

## インストール方法（Firefox）

Manifest V3・`chrome.*` API（Firefoxでは`browser.*`のエイリアスとして動作）のみを使用しているため、コード変更なしでFirefoxでも動作します。ただしFirefoxは拡張機能の恒久インストールに署名を要求するため、用途に応じて以下のいずれかを選んでください。

### お試し・一時利用（最も簡単、署名不要）

1. Firefoxで `about:debugging#/runtime/this-firefox` を開く
2. 「一時的なアドオンを読み込む…」をクリック
3. このフォルダ内の `manifest.json` を選択する
4. Firefoxを再起動すると読み込みが解除されるため、再度上記手順が必要です

### 恒久的に使いたい場合（署名が必要）

Mozillaの無料の署名サービス（[addons.mozilla.org](https://addons.mozilla.org/) の開発者向けハブ）で「Unlisted（非公開配布）」として`.xpi`に署名してもらうと、通常版Firefoxでも再起動を挟まず恒久的にインストールできます。公開リストには載らず、自分専用の配布として扱えます。

1. AMOの開発者アカウント（無料）を作成
2. このフォルダをzip化し、拡張子を`.xpi`に変更
3. 開発者ハブで「Submit a New Add-on」→「On your own」（Unlisted）を選択してアップロード
4. 署名済み`.xpi`をダウンロードし、Firefoxにドラッグ&ドロップしてインストール

※ Firefox Developer Edition / Nightly / ESRでは `about:config` の `xpinstall.signature.required` を `false` にすることで署名なしの恒久インストールも可能ですが、通常版Firefoxでは選択できません。

## 使い方

1. 拡張機能アイコンをクリック → 「⚙ 管理」から管理画面を開く
2. 種別（ログイン情報 / スイッチロール）を選び、必要事項を入力して「登録する」
3. 以後はツールバーのアイコンをクリックすると一覧が表示され、「開く」または「スイッチロールで開く」ボタンで対象のAWS環境にアクセスできます
4. 登録内容の変更は管理画面の「編集」、不要になった環境は「削除」から行います

## データの保存場所

- `chrome.storage.local`（Firefoxでは`browser.storage.local`相当）に保存されます。Google/Firefoxアカウントの同期対象外で、ブラウザ・プロファイルごとに独立しています。
- 拡張機能をアンインストールするとデータも削除されるため、必要であれば管理画面の「エクスポート」で定期的にバックアップをとってください。
- 別のブラウザ・PCへの移行手順: (1) 移行元で管理画面の「エクスポート」を押してJSONを保存 → (2) 移行先に本拡張機能を読み込み → (3) 管理画面の「インポート」で保存したJSONを選択。Chrome→Firefoxのように別ブラウザへの移行も同じ手順です。
