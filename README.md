# Account Deck for AWS

AWS のサインイン画面とスイッチロールを一覧にまとめ、ツールバーからワンクリックで開く Chrome 拡張機能です。

- 環境ごとに色とラベル（本番・STG など）を付けられるので、本番と開発を取り違えにくくなります
- 「開く」を押すと、AWS のサインイン画面にアカウントID・ユーザー名・パスワードを入力し、サインインボタンまで押します（パスワードを保存していない環境は入力まで。MFA のコードは自分で入力します）
- スイッチロールは、切り替え画面の「Switch Role」ボタンまで押します
- 保存したパスワードは必ず暗号化します。マスターパスワードで守ることもできます
- 日本語と英語に対応し、ライト/ダークは OS の設定に合わせます

Amazon Web Services の公式ツールではありません。AWS、Amazon Web Services は Amazon.com, Inc. またはその関連会社の商標です。

## インストール

Chrome ウェブストアで公開の準備中です。それまでは、下の「開発者向け」の手順で読み込めます。

## 使い方

1. インストールすると、初回案内が開きます。保存するパスワードの守り方（マスターパスワードを使うかどうか）を選びます
2. 「環境を追加」から、サインイン先かスイッチロールを登録します
   - ログイン: 表示名・アカウントID（12桁、またはアカウントエイリアス）・IAM ユーザー名・パスワード。サインインURLは空欄なら、アカウントIDから `https://<ID>.signin.aws.amazon.com/console` を作ります
   - スイッチロール: 表示名・アカウントID・ロール名。先に AWS マネジメントコンソールへサインインしておく必要があります
3. ツールバーのアイコン（または `Alt+Shift+A`）でポップアップを開き、「開く」を押します

ポップアップでは、開いてすぐに文字を打てば絞り込めます。`↑` `↓` で選んで `Enter` で開き、`Esc` で検索を消します。アカウントIDを押すとコピーできます。

## パスワードの守り方

パスワードは AES-GCM（256 ビット）で暗号化して保存します。鍵の持ち方は2つから選べ、あとから管理画面の「設定」で変えられます。

| | マスターパスワードを使う | 使わない |
| --- | --- | --- |
| 鍵 | マスターパスワードから作り、保存しない | 拡張機能が作り、この端末に保存する |
| 入力の手間 | ロックされたら入力する | なし |
| 自動ロック | 15分 / 1時間使わなかったら、またはブラウザを閉じたら | — |
| 向いている人 | PC をほかの人も使う | 自分だけが使う PC |

マスターパスワードを忘れると、保存したパスワードは取り出せません。設定の「マスターパスワードを忘れたとき」から、パスワードだけを消して設定し直せます。

## データの保存場所とバックアップ

- 登録内容はすべて、この端末のブラウザの中（`chrome.storage.local`）に保存します。同期はせず、外部へ送ることもありません。詳しくは [プライバシーポリシー](PRIVACY.md) を見てください
- 拡張機能を削除すると登録内容も消えます。管理画面の「設定 → バックアップ」から JSON ファイルに書き出せます。パスワードを含めるときは、ファイル用のパスワードで暗号化します
- 読み込みは、今ある環境への追加です（上書きしません）。v1（AWS環境ランチャー）のバックアップも読み込めます

## v1（AWS環境ランチャー）から移るとき

- 同じフォルダを読み込み直して更新した場合は、登録内容をそのまま引き継ぎ、平文で保存されていたパスワードを自動で暗号化します
- ストア版など別の拡張機能として入れる場合は、v1 の管理画面で「エクスポート」し、新しい版の「バックアップを読み込む」で読み込んでください。v1 のファイルにはパスワードが平文で入っているので、読み込んだら削除してください

## 開発者向け

### 読み込み方

1. `chrome://extensions` を開き、「デベロッパーモード」をオンにする
2. 「パッケージ化されていない拡張機能を読み込む」で `src/` フォルダを選ぶ

### フォルダ構成

```
├── src/                 # 拡張機能の本体（ストアに出す ZIP はこの中身だけ）
│   ├── manifest.json
│   ├── _locales/        # 文言（en / ja）
│   ├── background.js    # タブの作成と、サインイン画面への値の受け渡し
│   ├── popup.*          # ポップアップ
│   ├── options.*        # 管理画面（一覧・設定・初回案内）
│   ├── content/         # AWS のサインイン画面・スイッチロール画面で動くスクリプト
│   ├── lib/             # 保存・暗号化・文言・画面部品
│   ├── styles/          # 色や余白の共通トークン
│   └── icons/
├── icons-src/icon.svg   # アイコンの元データ
├── scripts/             # 画像の書き出し、ZIP の作成
├── tests/               # 単体テストと E2E 確認
└── PRIVACY.md
```

### テスト

```sh
npm install
npx playwright-core install chromium   # E2E と画像の書き出しで使う
npm test        # 単体テスト（暗号化・移行・バックアップ・文言の抜け）
npm run e2e     # 拡張機能を読み込んだ Chromium での通しの確認
```

E2E 確認は AWS に接続しません。Chromium の `--host-resolver-rules` で `*.signin.aws.amazon.com` をローカルの偽サーバーへ向け、AWS の画面に似せたページで確かめます（証明書は `openssl` でその場で作ります）。本物の画面で動くかは、実際の AWS アカウントで確認してください。

### 対応ブラウザ

Chrome（121 以降）と、Chromium 系のブラウザ（Edge など）が対象です。Firefox 向けの manifest の書き方（`background.scripts`）は、Chrome がエラーとして表示するので入れていません。
